Paid Consulting Project

Recruit WebApp

I work as a Lead Developer of web-based applications. The client of this project is a school bus company near London, ON. The objective is to replace an old MS Access database program with a WebApp. We developed a WebApp that helps to track applicants from when they apply for a job to when they get hired. I used MySQL for the database, Flask (python web framework) for the functionality and PythonAnywhere for testing deployment. The WebApp helped to implement more controls and transparency in the process. Now the project is in the pilot stage, with the App live on the company server
