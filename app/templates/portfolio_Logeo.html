Logeo (Nov – Dec 2020)

Demo Github

Summary

On November 2020, I took part in the Graphical Neural Networks Workshop by Aggregate Intellect. The workshop included product development and ML Ops modules. As part of the workshop, random teams were assigned. I was part of Logeo's Team and I was responsible for the deployment of the REST API to AWS. As part of the workshop, a small competition among the developed projects was run. We were selected as the winners!

Objective

To develop a webapp able to automatically transform 2D logos to 3D using Graphical Neural Networks (GNN)

Business Problem

3D desings can take hours to be developed, but with the help of AI, a 3D logo can be generated in minutes.

  • In 2019, $236 billion USD were spend in advertising
  • 3D ads outperformed traditional static ads, increasing sing-up conversion and click-through rates on websites

Business Opportunity

Use AI to automatically generate 3D logos, reducing desing time. We can apply RigNet to generate skeletons facilitationg 3D logos animations. RigNet applies GNN and can be used as a tool.

Tools

  • Flask (Python)
  • AWS EC2 instance
  • RigNet

Achievements

  • Deployment of a REST API using AWS Services
  • Presented results to the public and jury using online tools
