Recruit WebApp (Oct 2019 - Present)

Demo

Objective

Development of an API to improve the recruitment/training process of a local school bus company.

Business Problem:

The company was using a MS Access application for almost 10 years. After this period, different inefficiencies emerged such as:

  • The need for a portable solution available on tablets
  • The need to move organization to paperless in its recruitment/training process
  • The administrators required more flexibility in managing some of the data tables
  • The organization wanted to tighten controls for record-keeping purposes

Business Opportunity:

There was an opportunity to redesign and rebuild the current tool as a web application that is easily accessed on any device through a URL. This new application has the ability to:

  • Generate reports in CSV or PDF files, which can then be uploaded to other systems
  • Provide access to Users based on permissions for their roles, improving accountability
  • Ensure that users follow the standard processes, without skipping intermediate steps

Tools

  • Flask (Python)
  • SQL + SQLAlchemy
  • Pandas
  • HTML, CSS, JQuery
  • Pythonanywhere

Achievements

  • Working collaboratively with a UX designer, an Infrastructure Lead and a Project manager to successfully deliver the end product
  • Managed and negotiated client expectations and requirements
  • Integration of SQL database to Flask web application
  • Deployment of API in Pythonanywhere and company servers

Multiple users login with different roles

The dashboard helps alert management when KPIs are off track

Applicants are organized in a table that briefly summarizes their information

Applicants profile gives detailed information on their status

Personal information of the applicant can be collected and saved

• A Timer controls training time. Minimum time requirements must be met.

Reports are customized to business needs

Reports can be generated, specifying date range and different formats, for download

Administrative tools to delete applicants, change user permisions, among others, are available
