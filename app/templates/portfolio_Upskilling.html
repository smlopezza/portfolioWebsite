Microsoft AI Upskilling Journey (May – Aug 2020)

Sprint 6 Sprint 5 Sprint 2 Agorize

Summary

Our team participated in the MS Upskilling Journey ran by Agorize . As part of the challenge we developed different projects using Azure Cognitive services. We made use of chatbots, image recognition, object recognition, etc. with the idea to propose a solution to the different problems proposed in each mini-challenge. Our team won the 6th Sprint, and the public award for the 2nd Sprint. I wrote a blog post related with this experience.

Objective

To develop different projects involving machine learning and artificial intelligence tools from Microsoft Azure Cloud services

Sprints

Microsoft defined different topics for each of the six Sprints. Each team had to develop a solution to the problem that was presented to us

  • Sprint 6 - AI in Production & Responsible AI: (Winners) - We proposed to use Azure Computer Vision service to identify plates of cars with driving restrictions, helping authorities to ensure the compliance of "Pico y Placa" legislation.
  • Sprint 5 - Language & Speech in AI: We developed a chatbot to help increase awareness in Down Syndrome
  • Sprint 2 - Microsoft Azure & Earth wildlife: (2nd place + audience award) - We used a pretrained wildlife detection model on Azure to detect animals in camera traps photographies

Tools

  • Flask (Python)
  • Azure Cognitive Services
  • Microsoft Azure: Cloud Computing Services
  • Azure Websites

Achievements

  • Winners of 6th Sprint, Public award 2nd Sprint – Total participants: 535 from 39 countries
  • Developed different projects using AI and Azure Cognitive Services
  • Presented results to the public and jury using online tools
